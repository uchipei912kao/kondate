# きょうのごはん

家族向けの献立アプリ（iPhoneのホーム画面に置いて使うWebアプリ）。AIもネットもAPIキーも使わず、内蔵レシピ（約140品）から「主菜・副菜・汁物」を提案します。

- 人ごとに「生もの禁止（すべて加熱）」「減塩」「やわらかめ」「卵NG」などをボタンで登録
- 「作った！」で記録（写真は任意）。記録した料理は設定の期間（既定2週間）は提案から外れる
- 「ある食材から」で家にある食材を優先
- 材料の □ を押すと買い物リスト。LINEなどに送れる
- 記録はスマホの中だけ（localStorage）。設定からバックアップの書き出し・読み込み

## ファイル
- `index.html` 画面 / `app.js` ロジック / `recipes.js` レシピデータ（`R(id, 名前, 分類, 分, [タグ], "材料:量|…", [手順], ひとこと)`）
- `manifest.webmanifest` `sw.js` PWA（オフライン対応） / `icon-*.png`

## レシピの追加・タグ
- 材料名から 卵・乳・小麦・豚・牛・鶏・魚・えびかに・貝・大豆・きのこ・そば・落花生 のタグを自動付与
- 手動タグ: 生 / 塩分高め / かたい / 脂多め / 辛い / 糖質高め / ばらける / 軽め / やわらか / 春夏秋冬
